# Чат-бот для приложения Камиллиге

Этот проект предназначен для разработки интеллектуального чат-бота.

## Основные функции:
- Ответы на вопросы пользователей.
- Интеграция с API.

### Проблема:
Доступ к качественному образованию и быстрым ответам на сложные вопросы в любое время

#### Безопасность:
я использую зашифрованные .env переменные для защиты данных

##### Планы на будущее:
я планируете добавить голосовой ввод (Text-to-Speech) или поддержку туркменского языка.
